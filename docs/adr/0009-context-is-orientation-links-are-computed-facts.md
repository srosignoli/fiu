# Context around a Workout is orientation; its links are computed facts

A Workout is vertical by nature: one function, one bug, one Scenario. Understanding a codebase is also horizontal: what a module is for, who depends on it, what changes with it, which forces pull on it. Fiu adds that horizontal layer around Workouts without letting it touch what a Workout measures. It has three parts. **Links**, computed between source files (imports, and files that change in the same commits), are true by construction: no model writes them. **Around this code**, a short section in a Workout's README, is assembled by Fiu from a template out of the links and Atlas entries that already exist, with no model call, at save time, so it is frozen with the Workout ([ADR 0003](./0003-workouts-are-immutable-attempts-hold-outcomes.md)). **The Debrief**, shown after an Attempt finishes, says what the target itself is for, who calls it, the tension signals the links show (hidden coupling, blast radius, churn), and which neighbours to practise next.

The descriptions in this layer are the model's word, as in the Atlas ([ADR 0008](./0008-the-atlas-is-orientation-never-verified.md)): labelled, never Verified, never input to the gate, and practising nothing (`fiu map` and stats ignore them). Before an answer, the risk is not a false sentence but a true one that gives the answer away, so the context is written only from material whose author never saw the Workout, describes what is *around* the target and never the target itself, and drops any line naming what the Workout changed or removed. A dropped line never fails a Workout: the context is an extra, and must never cost a Verified one. Everything about the target waits for the Debrief, when there is nothing left to spoil.

We rejected letting the generating model write the context: it knows the bug, so its prose is the hardest to keep from hinting. We rejected model-written "trade-off" paragraphs for now: they are the most persuasive and least checkable part, so tensions start as computed signals, and the Debrief turns them into suggested Workouts, which are measured. We rejected a call graph between functions for the reason ADR 0008 rejected a parser; links are between files, found by each Language Profile's `importStyle`, and only those that resolve to a file in the repository count, because a missed link costs nothing and a wrong one misleads.
