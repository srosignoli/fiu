## Scenario

After each commit, Fiu makes a practice Workout in the background, with a limit of 5 generation attempts a day. It is 9:00 in the morning. At 11:50 last night, a commit's Workout took 2 attempts. At 7:30 this morning, another commit's Workout took 3 attempts before it passed. At 8:15 you asked Fiu for a Drill on a file yourself, which took 1 attempt. How many of today's 5 attempts does the limit count as used?

## What happens?

- 1: each commit Workout counts once today, however many attempts it took.
- 3: only this morning's commit Workout counts, every one of its attempts included.
- 4: this morning's commit Workout and the Drill you asked for both count.
- 5: commit Workouts from the last 24 hours count, last night's included.
