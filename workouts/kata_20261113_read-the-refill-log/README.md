## What it must do

`readLog(text)` turns the log file's contents into its entries, in the order they were written.

- `text` is the whole file: one JSON object per line, each ending in a newline. It is `undefined` when nothing has been logged yet: return an empty list.
- A line that isn't valid JSON (the last write was cut short when the machine went down) is skipped; every other entry is kept.
- Empty lines, such as after the final newline, are not entries.

## Where it fits
